Basics of Wireframe to Web Code

Get to know the basics of README files, website planning, and Git.

What is the purpose of a README file?

A README acts as a project's introduction. It gives visitors an overview of the software, explains any requirements, and provides instructions so they can get started without having to figure everything out themselves.

Learn more about README files

What is the purpose of a wireframe?

Before writing code, designers can sketch a webpage to decide how its different parts should fit together. This rough plan, called a wireframe, helps teams organise information and spot layout problems early in the process.

Learn more about wireframing

What is a branch in Git?

A branch in Git is a separate line of development. It allows developers to work on different features or experiments without affecting the main codebase. Once the work on a branch is complete, it can be merged back into the main branch.

Learn more about branches
